\#  School Management System



Full-stack School Management System xây dựng bằng Next.js, NestJS và SQL Server.



\## Tech Stack

\- Frontend: Next.js 16 (App Router) + Tailwind CSS

\- Backend: NestJS + Prisma ORM

\- Database: SQL Server (Docker)



\## Status

\- Project đang trong quá trình phát triển (Phase 1: Setup hoàn tất).



\## Local Setup

1\. `docker compose up -d` — khởi động SQL Server

2\. `cd server \&\& npm install \&\& npm run start:dev` — chạy Backend (port 3001)

3\. `cd client \&\& npm install \&\& npm run dev` — chạy Frontend (port 3000)
